# CharmEd Minds™ — Training & Program Materials

**Confidence Through Cognition and Education**

This repository holds staff-facing training and reference materials for
**CharmEd Minds™**, BHW Medical Group's lifespan cognitive-health and
executive-functioning program (ages 5–90).

## Contents

| File | Purpose |
|------|---------|
| [`CharmEd-Minds-Employee-Training-Guide.md`](CharmEd-Minds-Employee-Training-Guide.md) | The complete employee onboarding and training guide — program model, roles, patient journey, population tracks, screening battery, documentation/billing, and role competency checklists. |
| [`CharmEd-Minds-Competency-Assessment.md`](CharmEd-Minds-Competency-Assessment.md) | Employee competency assessment (trainee copy) — questions across core knowledge, scope/safety, patient journey, screening, documentation, role-specific items, and scenarios, with a sign-off block. |
| [`CharmEd-Minds-Competency-Answer-Key.md`](CharmEd-Minds-Competency-Answer-Key.md) | Trainer answer key with correct answers, scoring/passing standard, and module references. **Keep confidential from trainees during assessment.** |

Distribution-ready **Word (.docx)** versions of the guide and both assessment
copies, plus a **20-slide onboarding deck (.pptx)**, are generated from these
Markdown sources by the scripts in [`tools/`](tools/).

## Who this is for

Every CharmEd Minds team member:

- **Provider / NP (CRNP)** — clinical interpretation, diagnosis, care plans, billing
- **Assistant Program Director (APD)** — program operations, workflow ownership, weekly sessions
- **Care Coordinator** — intake, testing, weekly session delivery, documentation
- **Medical Assistant (MA)** — intake support, materials, scheduling, device setup
- **Front Desk** — scheduling, reminders, attendance compliance

## Important scope note

The tools referenced in this guide are **screening instruments**. They identify
patterns and referral needs; they do **not** replace formal diagnostic
evaluation (e.g., full ADHD, autism, learning-disability, or neuropsychological
testing) when a formal diagnosis is required. All clinical interpretation and
diagnosis is performed by the Provider. Non-clinical staff describe trends and
scores only — they do not diagnose or interpret clinically.

> This material supports the CharmEd Minds **clinical program**. It is distinct
> from the CharmEd Minds lifespan **research protocol** (a separate development
> draft not yet approved for participant enrollment or clinical claims).
